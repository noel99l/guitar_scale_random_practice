# ギター指板スケール練習ランダム表示アプリ

## 概要

ギターの指板上でスケール練習を行うための、シンプルなランダム出題アプリです。

ボタンを押すたびに、以下の4項目がランダムに表示されます。

- スケール
- 弦
- 度数
- 指

表示された条件をもとに、指板上で該当する音を探して練習できます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 画面中央の「ランダム表示」ボタンを押します。
3. 表示された条件に従って、ギターの指板上で音を探します。
4. 続けて練習する場合は、再度「ランダム表示」ボタンを押します。

スペースキーを押しても、ランダム表示を実行できます。

## ランダム表示される項目

### スケール

以下の12音からランダムに選択されます。

- C
- C#
- D
- D#
- E
- F
- F#
- G
- G#
- A
- A#
- B

### 弦

以下の6本の弦からランダムに選択されます。

- 1弦
- 2弦
- 3弦
- 4弦
- 5弦
- 6弦

### 度数

以下の度数からランダムに選択されます。

- Root
- 9th
- Maj3rd
- 4th(11th)
- 5th
- 6th(13th)
- Maj7th

### 指

以下の指からランダムに選択されます。

- 人差し指
- 中指
- 薬指
- 小指

## 機能

- スケール・弦・度数・指のランダム表示
- スペースキーによる再抽選
- 直近10件の履歴表示
- 履歴クリア機能
- スマートフォン表示対応
- 単一HTMLファイルで動作
